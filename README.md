   - **為什麼會紅？** 動物超可愛、在家免買門票看非洲野生動物、雙語與世界地理教材、3D 地球與專注計時。

   - **行銷的推手**：感謝 IG 創作者短影音剪輯推薦，精準痛點切入引爆數萬人潮擴散。
   - **創意思維的本質**：把想法變成「有意思且有意義」的作品；你是總建築師，AI 是技藝精湛的木匠。

2. **🏫 實戰一：3D 校園導覽開發實戰（參考 01 製作指南）**
   - 只要兩張圖：一張平面圖 ＋ 一張 115 教室配置表。
   - 純前端無後端架構（Three.js CDN、Base64 內嵌貼圖、雙擊直接開啟）。
   - **六大血淚踩坑**：
     - 方向旋轉 180° 大陷阱（配置圖上方不一定是北）。
     - 建物同義詞與別名機制（「土木館」vs「土木營建館」）。
     - Python 自動樹木偵測（Pillow + NumPy 自動萃取樹冠座標）。
     - CSS2D 標籤遮擋自動避讓。
   - **永續維護**：Google 試算表 CSV 串接，讓教務同仁每年自主維護更新。

3. **🏝️ 實戰二：3D 探索群島開發實戰（參考 02 製作指南）**
   - 10 座八角形浮空小島用木拱橋相連，中央為行政島。
   - **純程式低多邊形建模**：不依賴任何外部 3D 模型檔，幾十 KB 秒開。
   - **移軸微縮後製 (Tilt-Shift)**：景深模糊打造桌上模型玩具感。
   - **效能最佳化**：3,600 個物件靜態合併 (BufferGeometryUtils)，保住 43+ FPS。
   - **法規防線**：官網公告 Big5 轉碼與學生姓名「李OO」正規表達式遮蔽。
   - **遊戲化**：9 題適性測驗推薦群島、校園樹上藏 12 隻小松鼠。
