# 國立南大附中 3D 校園導覽

國立臺南大學附屬高級中學 115 學年度 3D 互動校園導覽網站。純前端靜態網頁，不需安裝或建置，直接以瀏覽器開啟 `index.html` 即可使用（也可直接部署到 GitHub Pages 等靜態主機）。

## 功能

| 功能 | 說明 |
| --- | --- |
| 3D 鳥瞰 | 依校園平面圖建置全校建築、道路、400 m 彩虹田徑場、各式球場與 1,500 餘棵樹木 |
| 樓層透視 | 點選有教室配置的大樓 → 選擇樓層，建築轉為半透明，顯示該層每間教室的位置與用途 |
| 搜尋 | 輸入班級（如 `315`）、處室（如 `健康中心`）、教室或建築名稱，直接飛往並標示 |
| 路線導航 | 選擇起點與終點，以 Dijkstra 演算法規劃最短步行路線，顯示距離、步行時間與轉彎指示，可「模擬帶路」 |
| 學程導覽 | 學術學程與 7 大專門學程，點選即標示相關館舍 |
| 地面漫步 | 以男／女同學角色第三或第一人稱漫步校園，具建築與樹木碰撞；手機使用搖桿 |
| 視覺主題 | 白天、黃昏、夜晚（窗戶與路燈點亮）、白模 |
| 其他 | 指北針、動態比例尺、校園平面圖小地圖（可點選飛往）、2D 平面視角、分享連結（`#b=legeng&f=2`） |

## 比例與方位

- 所有位置以 `campus-map.jpg`（2818 × 3792 px，**上方為北**）的像素座標記錄。
- 比例尺依 **400 公尺標準田徑場** 校正：平面圖跑道內場約 400 × 890 px，對應標準內場 73 × 157 m，得 **0.18 m/px**（`data/campus-data.js` 的 `map.metersPerPx`）。全校約 480 × 650 m。
- `classrooms-115.png` 的**上方為南方**（與平面圖相差 180°）。資料檔中的教室已完成方向轉換：東西向建築各樓層由「西 → 東」排列，南北向建築由「北 → 南」排列。
- 依指示修正：圖書館為 4 層樓；「學生宿舍」更名為「書庫」，為 5 層樓。

## 檔案結構

```
index.html              頁面結構
css/style.css           介面樣式（含手機版）
data/campus-data.js     校園資料：建築、場地、道路路網、教室配置、學程、漫步起點、快速視角
data/trees.js           由平面圖自動取樣的樹木位置
js/world.js             3D 場景：地面繪製、建築程序化建模、樹木、校門、主題、樓層透視
js/controls.js          鳥瞰相機操控（滑鼠、觸控、飛行動畫）
js/nav.js               路網與最短路徑、路線繪製、模擬帶路
js/walk.js              漫步模式角色與碰撞
js/app.js               介面互動：搜尋、資訊面板、導航、學程、小地圖、標籤
js/vendor/three.min.js  Three.js r149（MIT License）
assets/campus-map-small.jpg  小地圖用縮圖
```

## 換學年更新

只需修改 `data/campus-data.js`：

1. `academicYear`：學年度。
2. 各建築的 `rooms`：每層一個陣列，元素為 `R(名稱, 類型, 相對寬度)`。
   - 類型：`c1` 高一、`c2` 高二、`c3` 高三、`off` 行政處室、`sp` 專科教室、`lab` 實習／實驗室、`cm` 公共空間、`sto` 儲藏、`wc` 廁所、`st` 樓梯。
   - 班級名稱填三位數字（如 `"315"`），搜尋與顯示會自動變成「315 班」。
3. 建築外觀或位置：修改 `rect`（平面圖像素 `[西, 北, 東, 南]`）、`floors`、`door`（導航出入口）。

## 本機預覽

直接雙擊 `index.html` 即可。若瀏覽器限制本機檔案，可在此資料夾執行：

```
npx serve .
```
